# 📻 קשר – מכשיר קשר לצוות (בסגנון Zello)

אפליקציית לחיצה לדיבור (Push-To-Talk) שעובדת בכל טלפון דרך הדפדפן, ואפשר להוסיף אותה למסך הבית כמו אפליקציה.

## מה יש בה
**לכל משתמש**
- כפתור גדול לדיבור: לוחצים ומחזיקים (או לחיצה אחת), ובמחשב גם מקש הרווח
- בכל ערוץ מדבר אדם אחד בכל פעם, כמו בקשר אמיתי, עם צפצופי פתיחה וסגירה
- רשימת המחוברים בערוץ ומי מדבר עכשיו
- קבלת התראות מהמנהל, גם כשהאפליקציה סגורה

**למנהל בלבד**
- 🗺️ **מפה חיה**: כל המשתמשים על המפה. מי שמדבר מסומן באדום והמפה עוברת אליו, עם באנר שמראה מי מדבר, באיזה ערוץ, באיזה דיוק, וקישור ל-Waze או ל-Google Maps
- 📡 **ערוצים (קבוצות דיבור)**: יצירה, שינוי שם ומחיקה
- 👥 **משתמשים**: המנהל יוצר כל משתמש עם שם וסיסמה שהוא קובע, ויכול לשנות סיסמה בכל רגע (המשתמש מנותק ונכנס עם הסיסמה החדשה). בנוסף: ניתוק, חסימה ומחיקה
- 📡 **קבוצות**: אפשר לפתוח כמה קבוצות שרוצים, ובכל קבוצה מסמנים מי חבר בה. יש גם "חבר את כולם" ו"העבר לקבוצה" שמעביר משתמש מיד
- 🔔 **התראות פוש**: לכולם, לערוץ או למשתמש אחד. אפשר לסמן "דחוף", ואז אצל המשתמש תישמע אזעקה והמכשיר ירטוט עד שהוא לוחץ "קיבלתי". המנהל רואה מי אישר קבלה
- 🕘 **יומן שידורים**: כל שידור עם השעה, המשך והמיקום של הדובר

רק המנהל יכול ליצור קבוצות ומשתמשים. משתמשים לא יכולים להירשם לבד (אפשר לאפשר את זה עם `ALLOW_REGISTER=1`).

## 🔋 חיסכון בסוללה
- המיקרופון נפתח **רק בזמן לחיצה** ונסגר 20 שניות אחרי השידור האחרון
- מנוע השמע נכנס להשהיה אחרי 30 שניות בלי דיבור, ומתעורר לבד כשמישהו מתחיל לדבר (באייפון הוא לא נכנס להשהיה, כי שם אי אפשר להעיר אותו בלי נגיעה)
- המיקום נקבע במצב חסכוני, דרך רשת ו-WiFi. **ה-GPS המדויק נדלק רק כשלוחצים לדבר**, כך שהמנהל רואה את הדובר במיקום מדויק בלי שה-GPS יפעל כל הזמן
- המסך לא נשאר דלוק, אלא אם המשתמש מסמן "השאר מסך דלוק"
- עיצוב כהה, שחוסך סוללה במסכי OLED

## הפעלה מקומית (לבדיקה)
צריך Node.js בגרסה 18 ומעלה.
```bash
npm install
ADMIN_PASSWORD=הסיסמה-שלך npm start
```
פותחים בדפדפן את http://localhost:3000. שם המנהל: `admin`, והסיסמה היא מה שהגדרת.

> ⚠️ **בטלפונים, המיקרופון, המיקום וההתראות עובדים רק דרך HTTPS.** לכן לשימוש אמיתי מעלים לשרת עם HTTPS (ראו בהמשך).

## העלאה לאינטרנט (מומלץ: Render או Railway)
1. מעלים את התיקייה ל-GitHub
2. ב-[Render](https://render.com) יוצרים **New → Web Service** ובוחרים את ה-repo
   - Build: `npm install`  · Start: `npm start`
   - ב-Environment מגדירים `ADMIN_PASSWORD`
3. מקבלים כתובת `https://….onrender.com` ושולחים אותה לצוות

**חשוב:** כדי שהמשתמשים, הערוצים ומפתחות ההתראות לא יימחקו בכל הפעלה מחדש, צריך דיסק קבוע (Persistent Disk ב-Render, Volume ב-Railway). מגדירים `DATA_FILE=/data/data.json`, כש-/data היא נקודת החיבור של הדיסק.

אפשרות לבדיקה מהירה מהמחשב: `npx cloudflared tunnel --url http://localhost:3000` נותן כתובת HTTPS זמנית.

## הגדרות (משתני סביבה)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `ADMIN_PASSWORD` | `admin1234` | **חובה לשנות!** סיסמת המנהל |
| `ADMIN_USER` | `admin` | שם המשתמש של המנהל |
| `PORT` | `3000` | הפורט |
| `ALLOW_REGISTER` | `0` | אם מגדירים `1`, משתמשים יכולים להירשם לבד |
| `MAX_TALK_SEC` | `60` | זמן שידור מקסימלי בלחיצה אחת |
| `DATA_FILE` | `./data.json` | הקובץ שבו נשמרים הנתונים |
| `PUSH_CONTACT` | `mailto:admin@example.com` | כתובת קשר לשירות ההתראות (מומלץ לשים את המייל שלך) |

## התקנה בטלפון
- **אנדרואיד (Chrome):** נכנסים לכתובת ← תפריט ⋮ ← "הוספה למסך הבית"
- **אייפון (Safari):** כפתור השיתוף ← "הוסף למסך הבית". **באייפון, התראות פוש עובדות רק כשפותחים את האפליקציה מהאייקון במסך הבית** (iOS 16.4 ומעלה)
- בכניסה הראשונה מאשרים מיקרופון ומיקום, ואז לוחצים "🔔 הפעל התראות"

## מגבלות חשוב לדעת
- זו אפליקציית ווב, כך שכשהמסך כבוי או שעוברים לאפליקציה אחרת, **השמע והמיקום נעצרים**. ההתראות כן ממשיכות להגיע. מי שצריך לשמוע כל הזמן יכול לסמן "השאר מסך דלוק". כדי לקבל שמע ומיקום ברקע (כמו ב-Zello) צריך אפליקציה טבעית לאנדרואיד או לאייפון, ואפשר לבנות אותה על אותו שרת
- השמע עובר דרך השרת: כ-32KB לשנייה לכל מאזין. זה מתאים לצוותים של עשרות משתמשים
- יומן השידורים נשמר בזיכרון ומתאפס כשהשרת עולה מחדש. משתמשים, ערוצים והתראות נשמרים בקובץ
